## TONE RULES (apply to every post)

1. **No em dashes.** Ever. Use commas or colons.
2. **No "free" in promotional copy.** Use "no cost" or "complimentary."
3. **Never name the AI.** Reference it as "Pattern18" or "the coach," not by an internal name.
4. **No exclamation points** in serious copy. Save for celebratory moments only.
5. **No corporate-speak.** "Leverage," "synergy," "empower" — banned.
6. **Read it aloud before posting.** If it sounds like a brand wrote it, rewrite it.
7. **Founder voice is "Rae"** publicly. Never use Christy's real name in public copy until April 15, 2028.
8. **3.5:1 give-to-ask ratio per batch.** Calculate CTAs first, multiply by 3.5 = required value posts.
